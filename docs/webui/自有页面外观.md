# 自有页面的外观：与应用同一套 UI

登录页、账号管理页、用户管理页是我们自己的文档（上游渲染层零改动），
它们天然拿不到应用打包进去的样式，最容易做成"另一个产品"。
这里记录把三者拉回应用设计语言的做法与验证方式。

## 结论

三个页面**不写颜色/圆角/字体字面量**（仅有的例外是下面那三个红），全部使用 `var(--*)`，
令牌与字体来自 `/__eleckoi/app-tokens.css`——该文件在运行时从应用构建产物
`out/renderer/assets/index-*.css` 中提取：

| 提取内容 | 用途 | 为什么这样做 |
| --- | --- | --- |
| `:root { … }` | 亮色令牌 | 抄一份常量能解眼前，上游改主题就悄悄过时 |
| `:root[data-theme="dark"] { … }` | 暗色令牌 | 同上 |
| `@font-face { … }`（11 条） | Noto Sans 网络字体 | 拉丁字形与应用完全一致 |

唯一的例外是三个红（报错文字、`已停用` 标签、`停用` 按钮），令牌里没有语义色，
直接取应用自己的 `#d93025`（`avatar-crop.css`、`settings-panel.css` 同款）。

排除项：`@media (prefers-color-scheme: dark) { :root:not([data-theme]) { … } }`
——脱离媒体查询后它会无条件生效，把亮色主题吃掉。页面自己决定 `data-theme`，
所以只需要上面两块（`@media` 里那块靠"选择器含 `:not(`"识别并跳过）。

字体 `src` 里的 `./noto-sans-*.woff2` 会改写为 `/assets/noto-sans-*.woff2`，
否则相对路径会解析到 `/__eleckoi/` 下而 404。

## 主题跟随

| 页面 | 主题来源 |
| --- | --- |
| 登录页 | 沿用上次登录时记住的主题；没有记录则 **light** |
| 账号管理页 / 用户管理页 | 该账号的 `desktop_preferences['appearance.mode']` |

两个容易搞错的地方：

1. **"读不到设置"要落到 light，不是 system。** 上游 `UserSettingsStore` 给
   `appearance.mode` 的默认值是 `light`（`nativeTheme.themeSource = 存储值 ?? 'light'`），
   与操作系统无关。回退成 system 的话，系统是暗色的用户会在亮色应用里撞见暗色的账号页。
2. 登录前不知道是谁，无从读账号设置。账号/用户管理页会把解析结果写进
   `localStorage['eleckoi:theme']`，登录页优先用它——这样「退出登录 → 再登录」
   不会在门口闪一下反色。

主题在 `<head>` 里同步定下（`pageTheme.ts` 的 `themeBootstrap` / `loginThemeBootstrap`），
否则会先亮后暗地闪一下；`system` 模式还会监听系统切换。

## 控件规格（对齐应用本体，不是自拟）

取自上游 CSS 的实际取值：

- 输入框：高 34、圆角 7、字重 500、`--field-bg`，
  描边 `color-mix(in srgb, var(--text) 15%, transparent)`，hover 28%，聚焦只把描边换成 `--blue`（与应用一致，不加光圈）。
- 按钮：高 40、圆角 9、字号 13、字重 600、`min-width: 96px`；
  主按钮 `background/border: var(--blue)` + `color: var(--on-accent)`，
  次按钮 `border: var(--line-strong)` + `background: var(--surface-raised)`，
  禁用态用 `--field-disabled` + `--soft-text`（同应用）。
- 面板：圆角 12、`--surface-raised`、1px `--line`、`0 8px 24px var(--shadow-color)`。
- 表格：表头 `--muted` + `--line-strong` 下边线，行分隔用 `--line`。

键盘可达性上比应用多一条：`:focus-visible` 给 2px `--blue` 半透明描边
（鼠标点击不出现），不改变视觉基调。

## 验证

`pnpm webui:appearance`（9 条断言，已并入 `pnpm webui:verify`）：

- **A-1/A-2** 令牌样式表确实来自构建产物，且未混入媒体查询块。
- **A-3** 三页都引用令牌、无旧青绿色板残留、主题由 `data-theme` 决定。
- **A-4** 三页 CSP 放行 `style-src 'self'` 与 `font-src 'self'`
  （否则外链样式表与网络字体被 `default-src 'none'` 拦掉）。
- **A-6/A-7** 真实浏览器里的**计算样式**：亮色下背景 `rgb(255,255,255)`、
  主按钮 `rgb(19,168,255)`；暗色下 `--blue` 取到 `#36aef7`、背景 `rgb(19,19,26)`；
  字体为 Noto Sans。
- **A-10** 账号页/用户管理页把主题写进 `localStorage`；登录页无记录时是 light
  （而不是跟随系统）。
- **A-8/A-9** 截图（本目录 PNG），并附一张应用本体截图供并排对照。

做法说明：把服务端渲染的 HTML 原样抓下来、追加一段只读探针脚本，
再作为同源公开文件交给浏览器——量到的仍是真实 HTML + 真实 CSS + 真实字体。
副作用是这份副本没有 CSP，所以页面自身的 CSP 由 A-4 单独断言。
