# ElecKoi WebUI 发行说明

> 这份文件是 **GitHub Release 的说明正文**，由 `.github/workflows/web-image.yml`
> 在打 tag 时通过 `gh release create --notes-file` 直接读取。
> 发新版本前先更新这里，再打 tag——Release 上显示的就是 tag 那一刻的内容。

## 这是什么

[ElecKoi](https://github.com/eleckoi/ElecKoi) 的 **Docker 多用户 WebUI 分支**。

上游是 Windows 桌面客户端（Electron）。本分支让同一套内核以 **Docker 服务**运行：
浏览器打开就能用，一个实例可以服务多个用户，手机竖屏也做了适配。

**上游源码零改动。** 我们的东西全部以「新增文件 + 2 个构建期补丁」的形式存在，
由 `scripts/check-upstream-diff.mjs` 强制保证，因此上游更新时可以一条线 rebase。

## 怎么用

### 方式一：拉现成镜像（最快）

```bash
docker pull ghcr.io/darling2077/eleckoi-web:0.1.1

cp docker/.env.example docker/.env
openssl rand -base64 32        # 生成主密钥，填进 ELECKOI_MASTER_KEY
$EDITOR docker/.env
docker compose -f docker/compose.yml up -d
```

`docker/compose.yml` 里默认是本地构建；只想用现成镜像的话，把 `build:` 段删掉、
把 `image:` 改成 `ghcr.io/darling2077/eleckoi-web:0.1.1` 即可。

### 方式二：从源码构建

```bash
git clone -b webui https://github.com/darling2077/ElecKoi-web.git
cd ElecKoi-web
cp docker/.env.example docker/.env
openssl rand -base64 32        # 生成主密钥，填进 ELECKOI_MASTER_KEY
$EDITOR docker/.env
docker compose -f docker/compose.yml up -d --build
```

**首次构建约 20–40 分钟**（apt 依赖 + 886 个 pnpm 包 + Electron 相关下载），
这不是卡住，请勿中断。

完成后打开 `http://127.0.0.1:8790/login`，**注册的第一个账号自动成为管理员**。

## 部署前必须知道的三条

- `ELECKOI_MASTER_KEY` **一旦设定永不更换**。它是唯一能解开用户已存 API Key 的东西，
  换掉后那些 Key 全部无法解密且不可恢复。
- **公网部署必须同时配** `ELECKOI_CARD_ORIGIN` 与 `ELECKOI_APP_ORIGINS`，
  且两者必须是**不同的源**。只配前者服务会启动失败。
- 反向代理后必须开 `ELECKOI_TRUST_PROXY=1`，否则所有用户共用一个代理 IP，
  累计十次登录失败会让**全站**被限流十五分钟。后端读超时需 ≥300 秒
  （`POST /api/rpc` 会同步等待整个 Agent 回合结束才返回）。

完整说明见仓库 [`docs/webui/`](https://github.com/darling2077/ElecKoi-web/tree/webui/docs/webui)，
交给 AI 助手部署可让它直接读根目录的 [`CLAUDE.md`](https://github.com/darling2077/ElecKoi-web/blob/webui/CLAUDE.md)。

## 本版包含

- **Docker 多用户 Web 服务**：单实例多租户，每用户一个独立的 cordis 容器，
  空闲回收；会话列表、角色、模型配置各自隔离。
- **上游可一条线更新**：改动全部落在新增文件里，另配 2 个构建期补丁
  （POSIX 媒体路径分隔符、卡片跨源帧），由门禁脚本强制。
- **手机竖屏适配**：图标栏改为底部横排、正文宽度回收（390px 屏上正文从
  205px 提到 316px）、聊天壁纸铺满、模型选择弹窗改为上下两段、
  生成统计条换行可读、点抽屉外空白处收起侧栏。
- **自有页面与应用同一套外观**：登录 / 账号管理 / 用户管理三页复用应用的设计令牌，
  跟随亮暗主题。
- **站点图标**：上游 `index.html` 没有 favicon，这里补上了。
- **验收体系**：`pnpm webui:verify` 共 16 组、137 项断言，含浏览器端真实渲染检查
  （用 CDP 精确设定手机视口，绕开无头 Chromium 的 500px 宽度下限）。

AGPL-3.0-or-later，与上游一致。

**使用本服务的人有权获得对应的完整源码**——即本仓库这个 tag：

<https://github.com/darling2077/ElecKoi-web>

部署自己的实例时，请把 `ELECKOI_SOURCE_URL` 指向**你自己那份源码**的地址，
